# 30 岁、上海、关公司后跑外卖 60 天

## 场景

刚完成个独注销（参考 [opc-shutdown](../../opc-shutdown/SKILL.md)）。手头还有一辆电动车，手头现金不多，希望接下来 2 个月先跑外卖把生活成本撑住。

## Step 1：选平台

```bash
cd skills/opc-dagong

python3 scripts/gig.py "city=上海|wheels=电动车|hours_per_day=8|need_insurance=no|prefer=外卖"
```

输出（节选）：
- 美团骑手（专送）：估算日入 280-360 元；入门门槛低；订单稳定
- 饿了么蜂鸟（专送）：估算日入 260-340 元；订单稳定
- 达达快送（众包）：日入 200-300 元；订单不稳定但灵活

## Step 2：扩展类目对比

```bash
python3 scripts/gig.py "city=上海|wheels=电动车|hours_per_day=8|need_insurance=no"
```

不指定 prefer，看全量打分。把跑腿（闪送 / UU 跑腿）也纳入对比。闪送时薪上限可达 60-80 元 / h，但单量不稳。

## Step 3：60 天目标

| 周 | 动作 | 目标 |
|---|---|---|
| W1 | 美团蜂鸟二选一注册，押金不超 500 | 第一周熟悉熟单区域 |
| W2-4 | 锁定一家专送，每天 8 小时 | 月收入 7000-9000 |
| W5-8 | 加 1 天闪送补单 | 月收入 8000-11000 |

## 60 天后

如果跑外卖之后觉得还不错 → 继续跑，把这变成主收入。
如果想换轻成本试错 → [opc-baitan](../../opc-baitan/SKILL.md)（摆摊）。
如果跑道还行想休整 → [opc-tangping](../../opc-tangping/SKILL.md)（看 runway）。

## 风险与免责

- 电动车 / 摩托车违规上路、超速会被吊销资格
- 平台抽成 20-30%，旺季淡季差距大
- 不要刷单 / 套保险，平台违规直接封号
- 数据来自公开报道与平台公告，最终以平台政策为准
