# 老铁口播脚本示例

输入：

```bash
python3 scripts/script.py "县城超市利润真相|老铁|普通人"
```

输出（节选）：

```json
{
  "topic": "县城超市利润真相",
  "style": "老铁",
  "style_label": "老铁喊话",
  "audience": "普通人",
  "tone": "亲切、口语、敞亮",
  "subtitle_style": "黄底黑字大字号",
  "bgm_hint": "二人转 / 喊麦节奏",
  "sections": {
    "opening": "老铁们，今天讲讲 县城超市利润真相，普通人 都得听。",
    "empathy": "我知道很多老铁在 县城超市利润真相 上吃过亏，咱不藏着掖着，今天敞亮聊。",
    "fact": "事实就是 便宜不一定差，贵的不一定好，不信你看身边人。",
    "twist": "真正能解决的办法是 先列三个硬指标再决策，我自己干过 三个月。",
    "cta": "觉得有用的双击屏幕，关注我，下条聊 进阶玩法。"
  }
}
```

## 拍摄建议

- 黄底黑字大字号字幕，背景 BGM 选二人转/喊麦节奏
- 镜头怼脸建立共情，CTA 段落要喊出"双击+关注"
- 老铁文化重在敞亮、不绕弯，避免堆术语
