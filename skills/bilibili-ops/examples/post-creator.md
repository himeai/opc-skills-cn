# 动态/专栏文案示例

## 动态（短文案）

输入：

```bash
python3 scripts/post.py "我用 30 天搭建一人公司|创业|动态"
```

输出（节选）：

```json
{
  "format": "动态",
  "max_chars": 233,
  "title": "",
  "body": "新视频聊了 我用 30 天搭建一人公司：创业新人最容易跑偏的几个动作。B 站观众 应该会感兴趣，三连蹲一波👇 #B站新视频#",
  "tags": ["#一人公司", "#创业复盘", "#自由职业", "#个人IP", "#知识区"]
}
```

## 专栏（长图文）

输入：

```bash
python3 scripts/post.py "我用 30 天搭建一人公司|创业|专栏"
```

输出（节选）：

```json
{
  "format": "专栏",
  "max_chars": 4000,
  "title": "我用 30 天搭建一人公司 ｜ 给 B 站观众 的一篇长文整理",
  "body": "## 写在前面\n\n这篇专栏是我配套视频《我用 30 天搭建一人公司》的图文版...\n\n## 核心结论\n\n- 把目标拆得足够小\n- 用最小可行版本试错\n- 复盘比执行更重要"
}
```

## 使用建议

- 动态正文 ≤ 233 字符，与 B 站客户端发布上限对齐
- 专栏支持 Markdown 标题 / 列表，复制到 B 站专栏编辑器即可保留结构
- tags 仅作参考，发布前请按当前热点替换
