```bash
python3 scripts/script.py "我用 30 天搭建一人公司|复盘|创业新人"
```

## 拍摄建议

- 复盘风格建议口播 + B-roll 实景穿插，每个 body chapter 留 5-10 秒空镜衔接
- intro 控制在 30 秒内抛核心结论，避免观众划走
- outro 留三连引导，不要拖太长
