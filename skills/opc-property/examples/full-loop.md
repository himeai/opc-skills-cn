# 完整链路示例：从「3000 万该买哪」到「钱怎么合规出去」

> 主人公：**老 W**，做了 5 年一人公司 SaaS，最近被收购，到手 3000 万 RMB。
> 35 岁，太太 + 一个 6 岁的孩子，杭州人。

## Step 1 — 先问：到底买在哪里

```bash
python3 scripts/match.py "budget_cny=3000w|purpose=自住|family=有学龄子女|residency=希望第二身份|risk_pref=中"
```

工具识别为「**三千万级**」段位，给出建议：
- 国内可看 A/S 级（前滩天悦 / 华润润府 / 深圳湾一号入门户型）
- 海外预算够进 迪拜 / 新加坡 / 悉尼 / 温哥华 / 洛杉矶

老 W 看完，发现「希望第二身份」+「子女教育」两条偏好下，迪拜（金签）和新加坡（GIP 太贵）形成对照——心里有数了。

## Step 2 — 国内城市排序：他犹豫上海还是杭州

```bash
python3 scripts/cn_city.py "budget_cny=2000w|priority=学区"
```

输出：上海 7.96、北京 7.57、深圳 7.09、杭州 6.91、苏州 6.70。
- 上海第一是因为学区 + 文化 + 流动性三板加权高
- 杭州虽然是老 W 主场，但学区项被拉低
- 老 W 决定杭州留 1500 万改善（之江九里），剩下 1500 万出海

## Step 3 — 海外市场对照：迪拜还是新加坡？

```bash
python3 scripts/global_market.py "budget_cny=1500w|residency=希望第二身份|tax_pref=低税|family=有学龄子女"
```

输出：
- 迪拜得分最高（金签 + 零税 + 学区差但国际学校多）
- 新加坡因 ABSD 60% 进场成本被打低（1500 万实际只够买 600 万级公寓 + 900 万印花税）
- 葡萄牙黄金签证房产路径已关闭，工具明确标出「已废」

老 W 决策：迪拜 Downtown 一套 AED 800 万（约 RMB 1500 万）公寓，叠加 10 年金签。

## Step 4 — 5 年持有成本对比

```bash
python3 scripts/holding_cost.py "city=迪拜|total_cny=1500w|hold_years=5|rent_out=yes"
python3 scripts/holding_cost.py "city=新加坡|total_cny=1500w|hold_years=5|rent_out=yes"
```

迪拜结果：
- 一次性税 4%（DLD）
- 年物业 1.5%
- 租金收益 6.5%（净 6.5%，无所得税）
- 5 年总成本约 ¥600 万（含进场 / 退出），隐含年化打平点 ~4%

新加坡结果：
- ABSD 60% 一次性印花税
- 5 年总成本约 ¥1100 万，隐含年化打平点 14%+

数字一摆，迪拜赢面明显。

## Step 5 — 钱怎么合规搬出去

```bash
python3 scripts/compliance.py "amount_cny=1500w|target_country=阿联酋|use=境外购房|family_size=3"
```

工具明确：
- ❌ **个人 5 万美元额度不能用于境外购房**（结售汇规定，写在脸上）
- ❌ **ODI 不得用于房地产敏感行业**
- ✅ 推荐路径：**先取得外国身份再以外籍买家配置**——例如先拿迪拜金签 + 当地银行资产证明，资金通过合法路径汇入

工具同时提示：
- 一家 3 口理论年额度 ¥108 万，搬完 1500 万要 14 年——这条路对置业本身不可行
- CRS 框架下海外账户可被中国税务获取
- 必须找持牌律师 + 私行客户经理走结构化方案

老 W 看完，预约了某中资行迪拜分行的私行经理。
