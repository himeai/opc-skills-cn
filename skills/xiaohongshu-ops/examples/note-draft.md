# 示例：把选题扩成结构化笔记

## 输入

```bash
python3 scripts/note.py "国货平价精华怎么选|护肤|25-30 岁敏感肌女性|经验分享"
```

## 输出

```json
{
  "title_candidates": [
    "✨ 25-30 岁敏感肌女性必看！国货平价精华怎么选的真实经验",
    "用了半年才敢说：国货平价精华怎么选",
    "国货平价精华怎么选｜踩过的坑都写在这了"
  ],
  "cover_copy": "亲测有效",
  "body_outline": ["开篇钩子", "我的背景", "踩过的坑", "现在的做法", "结果与反馈", "总结提醒"],
  "tags": ["#敏感肌护肤", "#国货之光", "#护肤心得", "#精华推荐", "#平价好物"]
}
```

## 用法

把 `body_outline` 当填空提纲，按段写真实经验，比"AI 全文生成"更不容易翻车。
