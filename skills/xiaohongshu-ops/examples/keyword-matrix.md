# 示例：单产品关键词矩阵

## 输入

```bash
python3 scripts/keywords.py "辅食研磨碗|母婴"
```

## 输出

```json
{
  "core": ["辅食研磨碗", "辅食", "玩具", "推车", "学步鞋", "尿不湿"],
  "long_tail": ["辅食研磨碗 6 月辅食工具", "辅食研磨碗 0-1 岁玩具推荐", "辅食研磨碗 辅食研磨碗"],
  "tags": ["#新手妈妈", "#辅食日记", "#宝宝好物", "#母婴育儿", "#育儿经验"]
}
```

## 用法

- `core`：标题中保证至少出现 1 个
- `long_tail`：放在文中关键段
- `tags`：发布时挂 3-5 个，不要全挂
