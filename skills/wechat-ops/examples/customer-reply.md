# 示例：48 小时窗口内的客服文本回复

## 适用条件

- 用户在过去 48 小时内向公众号发送过任意消息（关注、留言、点击客服菜单等）
- 超出 48 小时调用本接口将得到 `45015` 错误码

## 步骤

```bash
python3 scripts/reply.py "oABCD12345EFGH67890|资料已发邮件，请注意查收。"
```

输出：
```json
{"status":"ok","touser":"oABCD12345EFGH67890"}
```

## 合规注意

- 仅用于回应用户主动发起的咨询
- 不得用于群发营销、骚扰、诱导分享
- 内容需符合《互联网信息服务管理办法》
