# 上海街头烤肠摊 30 天 ROI

## 场景

刚完成个独注销（参考 [opc-shutdown](../../opc-shutdown/SKILL.md)）。手头 3000 元启动资金，想试试夜市卖烤肠 / 关东煮 / 玉米肠。

## Step 1：政策 + 品类查询

```bash
cd skills/opc-baitan

python3 scripts/stall.py "city=上海|budget_cny=3000|category=小吃热食|night_or_day=night"
```

输出（节选）：
- 上海开放夜市点位（合规摆点）+ 备案路径
- 小吃热食典型毛利 50-65%
- 起步成本 1500-5000 元 → 你的 3000 元 in_budget = true
- 设备清单：折叠摊位 / 推车、灯具、收款码、不锈钢操作台、煤气罐 / 电磁炉、餐厨垃圾袋 + 餐厨垃圾签约
- 必备资质：健康证 + 摊位备案卡

## Step 2：ROI 估算

| 场景 | 日单量 | 日毛利 | 月毛利 (25 天) | 回本天数 |
|---|---|---|---|---|
| 低 | 30 单 | ~150 元 | ~3,750 元 | ~20 天 |
| 中 | 50 单 | ~250 元 | ~6,250 元 | ~12 天 |

未扣摊位费 / 通勤 / 损耗 / 个人时薪机会成本，仅看毛利。

## Step 3：30 天时间线

| 周 | 动作 |
|---|---|
| W1 | 办健康证（杭州 / 上海各区卫健窗口，约 3-5 天）；买推车 + 烤肠机 + 食材；摊位备案卡 |
| W2-4 | 每晚 18:00-23:00 出摊；试 3 个不同点位看人流 |

## 30 天后

如果跑通了 → 继续摆，考虑加固定的市集摊位。
如果跑不通 → 切到 [opc-dagong](../../opc-dagong/SKILL.md)（外卖比摆摊单量稳定）。
现金流不行 → [opc-tangping](../../opc-tangping/SKILL.md)（先把跑道铺出来）。

## 风险与免责

- 食品安全是底线，进货渠道必须可追溯（不要从来路不明的批发市场拿货）
- 占用消防通道 / 占道经营会被城管扣货
- 健康证必须真实办理（《食品安全法》强制）
- 数据来自公开政策与运营方公告，最终以当地城管 / 卫健窗口为准
